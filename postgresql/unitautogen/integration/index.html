Team

Test the whole flow,
not just the unit.

Where unit testing checks a routine on its own, integration runs it together with the functions it calls and the triggers its writes fire, for real, and measures coverage across all of it.

Get started Back to overview

The real call map, exercised

A function that calls nothing and fires no triggered write is standalone, and its integration result is identical to its unit test, so it is noted rather than duplicated. For everything with a real call map, integration produces a full set of tests per root function - valid inputs, boundaries, one per branch - run through the actual call chain, so a line uncovered here is one the root's inputs never reached through the whole flow.
