Get started
with UnitAutogen for PostgreSQL.

Download the build for your platform, install the two extensions in your database, and generate your first pgTAP suite with coverage.

Download Read the docs

Your first run

unitautogen --schema public --out unit_tests --html report.html --json report.json
  • PostgreSQL 14 to 18, self-hosted or managed (Supabase, Neon, RDS and Aurora, Azure Database for PostgreSQL)
  • Needs pgTAP and plpgsql_check installed in the database you are testing
  • Generated tests are standard pgTAP - commit them and run them in CI with no UnitAutogen at run time
  • Ships as a single self-contained binary for Windows and Linux
  • Runs entirely on your side, with no telemetry
  • Beta (v0.3.2): validated at high coverage across a range of real schemas
