What it maps to

The isolation results map onto the controls that require you to prove data is reachable only by those authorized. For HIPAA, per-routine evidence for Access Control (45 CFR 164.312(a)(1)), and, run continuously, support for the periodic technical Evaluation (164.308(a)(8)). For SOC 2, logical and role-based access controls (CC6.1, CC6.3) and the Confidentiality criteria (C1) where the data is sensitive. Because the scans run on every deploy, the reports show the controls operated across the audit period, not just that they were designed.

This is supporting evidence for your auditors, framed as a tool. UnitAutogen does not issue a certification and does not run audits for you.
