Available for PostgreSQL - free in the Community Edition

Unit tests for your database logic,
without writing them.

You own functions, procedures and triggers that nobody has unit-tested, because writing the tests means faking every table and crafting the data for every branch. UnitAutogen generates the tests and that data from the code itself, runs them, and tells you exactly which lines and branches ran.

Get started See coverage

What you get for each routine

A test per branch

Every IF, CASE, loop and exception handler gets a test that drives it, on both its true and false side, with the boundary values around each numeric gate.

The data that makes it real

Each test seeds the exact rows the branch depends on, including required columns and foreign-key parents, in the native test framework's own isolation so nothing persists.

Assertions on behaviour

Return values, result sets, and the rows a branch inserts, updates or deletes are asserted, so a broken branch fails instead of passing against an empty table.

How it fits your day

Run it against a throwaway copy of the database. The generated suite lands as ordinary test files you can read, edit and commit next to your migrations. Re-run it after a change and the diff shows which behaviour moved. Wire it into CI and a change that alters a routine's behaviour fails the build before it reaches production.

What it cannot test reliably, it says so, per line, rather than showing a green that would mislead you. Never a fabricated, false-passing or flaky test.
