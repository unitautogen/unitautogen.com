Why it matters for tests specifically

  • A test suite is only worth what it rules out
  • A wrong test is worse than none: it fails when the code is fine, or passes when it is broken
  • You cannot find the wrong ones without the oracle you were trying to generate
  • Scaling a model changes the error rate, not the error kind
Never a false pass is a property of the algorithm here, not a promise. A model still earns its place at the edges - naming a test, summarising a routine, triaging a flagged case - never in the correctness core.
