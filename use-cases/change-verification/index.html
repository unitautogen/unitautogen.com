They manage the change.
We verify it.

Migration tools deploy your change safely. None of them check the logic still behaves the same.

  • Generated tests pin today's behaviour as pgTAP
  • A change that moves a pinned behaviour fails the build
  • Real branch coverage, not a deploy log
  • Sits on top of the migration tool you already run

The gap

  • Flyway, Liquibase and Bytebase version, deploy and govern schema changes
  • A migration that redeploys a function ships whatever it now does
  • Nothing checks it still returns what it returned yesterday
  • UnitAutogen's generated unit and integration tests do
